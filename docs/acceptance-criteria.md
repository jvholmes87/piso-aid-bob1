# Acceptance criteria

These criteria define how Bob 1 test evidence will be evaluated. No target has been approved and no criterion has been tested.

| Metric | Definition | Measurement method | Target | Status |
|---|---|---|---|---|
| Route-following error | Cross-track distance between planned route and measured vehicle position, in meters | Compare timestamped GPS track with planned route and calculate cross-track error | TBD, set by project lead | Not yet tested |
| Endurance at defined payload | Elapsed operating time, in minutes, at a documented payload and operating condition | Time a complete run from start to stop while logging payload, battery state, and operating profile | TBD, set by project lead | Not yet tested |
| Measured payload vs. flotation calculator prediction | Difference between measured supported payload and calculator prediction, expressed as percent | Measure as-built mass, test payload, and observed flotation condition; compare with calculator output | TBD, set by project lead | Not yet tested |
| Operator interventions per run | Count of operator overrides, aborts, route corrections, or safety interventions during one run | Maintain timestamped intervention log and correlate with autopilot log | TBD, set by project lead | Not yet tested |
| Telemetry link reliability | Percent of run time with usable telemetry link | Compare telemetry availability timestamps with total run duration | TBD, set by project lead | Not yet tested |
| Manual-override response | Time from operator override command to confirmed manual control | Timestamp override input and corresponding control-state change in logs | TBD, set by project lead | Not yet tested |
| Build cost vs. bill of materials estimate | Difference between documented actual build cost and approved BOM estimate | Reconcile invoices/receipts against version-controlled BOM | TBD, set by project lead | Not yet tested |
