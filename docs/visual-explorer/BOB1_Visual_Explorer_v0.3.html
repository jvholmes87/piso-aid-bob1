Calculation basis and limits

Equations use SI units internally. Draft is solved from circular-segment area using bisection, with equal loading and level trim.

For radius r and draft d: A = r² acos((r − d)/r) − (r − d) √(2rd − d²); supported mass = density × 4 × equivalent length × A. Crown clearance = 2r − d. Crown clearance is not deck freeboard.

The stability screen below the load note is taken from the 12 September 2026 hull estimate (initial GM = KM − KG, KG assumed 450 mm, drum-row spacing 400–440 mm). It is a sensitivity band, not a measured property. See the draft and stability chart.

This calculation does not establish structural capacity, load placement, wave response, or safe payload. Actual drum geometry, sealed external volume, and measured masses must replace these assumptions.
