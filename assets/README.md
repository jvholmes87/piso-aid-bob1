# Public visual assets

The repository README retains Jason’s original CAD isometric image.

- `images/bob1-component-concept.png`: simplified component-group schematic.
- `animations/bob1-assembly-concept.gif`: six-second looping schematic animation.
- `diagrams/system-architecture.mmd`: editable Mermaid source for the proposed architecture.
- `source/build.py`: Python/Pillow source for reproducing the PNG and GIF. Run with Python 3 and Pillow; the script uses the DejaVu Sans font available on many Linux systems. Outputs are written beside the script and can be copied to the image and animation folders.

The new PNG and GIF are programmatically drawn explanatory graphics. They are not CAD exports, validated mechanical drawings, a demonstrated assembly sequence or evidence of operational performance. Drum placement is simplified and propulsion is omitted. The system architecture is proposed, not a detailed wiring design.
