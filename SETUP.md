# Maintaining the public repository

Repository: https://github.com/jvholmes87/piso-aid-bob1

This public repository contains the project overview, development status, roadmap and collaboration guidance. Keep these documents current as development progresses; date progress reports and distinguish proposals from demonstrated results.

For updates, use a focused branch and pull request explaining the change and its supporting evidence. Check relative links before merging.

Detailed design reviews, source inventories, purchasing records and private source links belong in the separate private review package. Share that package individually by arrangement with the project lead. Do not upload the earlier combined starter or the private package into this repository.
