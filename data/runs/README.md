# Bob 1 test-run data

This folder is reserved for evidence from actual Bob 1 tests. No test-run results are present at project version 0.5.

Use one directory per run:

`YYYY-MM-DD-run-NN/`

Each run directory should contain or reference, as applicable:

- GPS track
- Battery data
- Operator-intervention log
- ArduPilot dataflash log
- Short run notes
- Test stage and configuration
- Defined payload
- Environmental observations
- Anomalies
- Acceptance-criteria assessment

Do not add inferred, simulated, or placeholder results in a way that could be mistaken for physical test evidence. Simulations, if used later, should be clearly labeled and stored separately from physical run data.
